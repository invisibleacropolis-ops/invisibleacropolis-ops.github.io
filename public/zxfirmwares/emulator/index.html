Emulator & tests

Local simulation only. No device connection, flashing or automatic firmware download. The included bring-up fixture is original diagnostic code, not the custom OS. Direct file imports are temporary. Version Library images, run receipts and opted-in debug logs persist locally in the owning project; they are not uploaded. Use complete project backups for durability beyond browser data.

Load a build

Raw XIP binary (2 B–1 MiB), mapped at 0x02000000. Supply its real entry point. SMK-37 Pro is the primary target; FM-1 uses the same PI32 CPU with its own board/peripheral model. Select the firmware’s intended board explicitly: shared core does not imply interchangeable panels, save layout or firmware packages. This loader accepts raw builds only, not ELF/ZIP/FWSC update containers. Upstream 1 MiB simulated main RAM is not measured owner-unit capacity.

Default: SMK-37 Pro. Reset preserves the loaded target; changing this selector does not retarget a running image.

Debug output / durable project recording

This is the emulated guest DBG_MSG console, model observations and host lifecycle—not Android logcat or a full instruction trace. Recording stays in the owning project’s browser-local Debug Sessions container. Only acknowledged checkpoints are durable; closing the browser can lose an unflushed tail. The live view shows the last 200 events/200,000 characters; saved chunks retain the full accepted sequence up to the explicit run budget. Guest-console trimming/loss is recorded as byte-offset gap events.
